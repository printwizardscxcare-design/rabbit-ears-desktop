# Local caption translation

The app bundles Meta's [M2M100 418M](https://huggingface.co/facebook/m2m100_418M), revision `55c2e61bbf05dfb8d7abccdc3fae6fc8512fd636`, converted to int8 with CTranslate2. The upstream model card declares MIT. Its model card is distributed beside the model.

The translation runtime uses CTranslate2 4.6.0 (MIT), SentencePiece 0.2.0 (Apache 2.0), NumPy (BSD and bundled library notices), CPython 3.12 (PSF and bundled library notices), setuptools/pkg_resources, and PyYAML. PyInstaller 6.14.2's bootloader exception permits distribution of the frozen helper. Full upstream license texts, copyright notices, and their pinned source URLs and checksums are distributed in `licenses/`. The exact installed package versions and their packaged license files are additionally copied into `licenses/build-runtime/` at build time.

CTranslate2's Windows wheel also carries Intel OpenMP 2023.0 and NVIDIA cuDNN 9.1.0, and statically links oneDNN 3.1.1. Their licenses and oneDNN's third-party notices are included, along with the pinned CTranslate2 source dependencies' notices. The cuDNN library is retained because the pinned Windows wheel requires it to load, even though this helper performs CPU inference. The NVIDIA license is supplied as the complete archived upstream HTML document. OpenSSL's license covers the CPython SSL libraries. The CPython source license fallback is pinned to 3.12.10; builds also copy the actual interpreter's license when supplied by its installation. Some bundled notices concern platform-specific components that may not be present on every operating system.

Translation runs locally, in a separate process limited to two inference threads. Machine translation can mistranslate dialogue and names. The original caption track stays available. Recognition and translation do not change the media or programme clock.
