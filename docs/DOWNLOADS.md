# Download rabbit-ears.stream desktop

Use the installer for your computer, not GitHub's Source code ZIP. Beta 9 includes multilingual speech models and local caption translation; no Python installation, speech account or separate model download is needed.

Internet is required for streams. Windows is unsigned; Mac builds are ad-hoc signed and not Apple-notarized. Windows updates ask before downloading and restarting. Mac and Linux updates use a replacement app/package. Saved preferences remain in the same profile.
