# 0.1.0 Beta 6

- Lowercased the brand in the app's visible title: **rabbit-ears.stream Desktop**. This applies to the title bar and operating-system window title.
- Consolidated the desktop footer even when an older page is cached. Startup requests fresh page markup and Reload bypasses the cache; the shared layout adapter also handles legacy markup without reloading the video.
- Added a beer-cup button to the right of Settings, opening the team Ko-fi page in a separate tab/browser.
- Added the permanent Rabbit Ears Discord invite to the footer and matched scrollbars to all nine viewing themes.
- Keeps the existing installation identity and profile, including saved preferences and sign-in.

Windows users can choose **Help → Check for app updates**. Mac/Linux users can install the replacement app or package from the [download page](https://rabbit-ears.stream/desktop/).
