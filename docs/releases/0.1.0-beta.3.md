# 0.1.0 Beta 3

- Restored every app menu in the normal window: Rabbit Ears, Navigate, View, Captions, Audio, Settings and Help. Headings open the existing native dropdowns with their current settings, shortcuts and actions.
- Menus and the title bar hide in Pop out and return when you choose Return. The same window and video remain in use.
- Pop out now keeps the current skin's TV bezel, logo, dials and transport controls. Resize or drag the TV to place it where you want it. The minimum compact-window height accommodates the bezel and controls.
- Website code, deployment and saved website caption preferences are unchanged. This is a desktop-only correction.

Validation: 116 Node checks; real Electron clicks on every app menu heading open its native dropdown; the 20 caption-appearance comparisons and compact/Return checks pass. A live-site check inside the desktop app verified the bezel and transport in all nine skins at 360×320 and 640×440, without website caption-preference writes or a second player.

Windows users can choose **Help → Check for app updates**. Mac/Linux users should quit and install the replacement app/package. Caption text burned into a video's pixels cannot be restyled. Windows is unsigned; Mac builds are ad-hoc signed and not Apple-notarized.
