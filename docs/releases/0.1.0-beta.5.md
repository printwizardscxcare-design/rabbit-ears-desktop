# 0.1.0 Beta 5

- Added **Help → Buy the team a beer**, opening the Rabbit Ears team support page in your browser. The site footer uses the same support destination, so payment details can be managed without another app update.
- Includes theme-matched Audio controls on Windows, Mac and Linux; all normal-app menus; and the same-window Pop out TV with its themed bezel and transport.
- Keeps stream-first captions and bundled speech fallback. Caption size/color apply to supplied tracks and engine captions; baked-in picture text cannot be restyled.

Windows: **Help → Check for app updates**, or run the new installer. Mac/Linux: quit and install the replacement app/package. The Windows beta is unsigned; Mac builds are ad-hoc signed and not Apple-notarized.
