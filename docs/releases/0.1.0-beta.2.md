# 0.1.0 Beta 2

- Fixed caption size/color applying only to engine output. The desktop choices now style provided tracks and engine captions alike, persist across reload/source changes, and apply in fullscreen/compact views.
- Kept caption appearance local to the desktop profile. The app applies site caption rendering preferences in memory rather than clicking persistent website settings; no website source/deployment is changed.
- Pop out now converts the same window into a borderless screen/transport. Return restores normal app bounds and maximize state. No new player/window, media reload, seek or pause change.
- Added local draggable title controls for the full app and draggable video/panel space in compact mode. Settings and authentication remain accessible in the normal app.

Validation: 115 Node tests; 20 real Chromium stream-vs-engine size/color comparisons across all five sizes and both colors, windowed/fullscreen. The real Electron test also checks source changes, site-CC synchronization, reload, zero website preference writes, and compact/return keeping one window, the same video/source/clock/pause and original bounds. Baked-in text remains part of the video picture and cannot be restyled.

Downloads are available for Windows x64, Apple Silicon and Intel Macs, and Debian/Fedora/Arch x64. All platform build and installation checks passed; published file hashes match their build manifests. See the [download table and platform guides](https://github.com/printwizardscxcare-design/rabbit-ears-desktop#download--010-beta-2) and [validation details](https://github.com/printwizardscxcare-design/rabbit-ears-desktop/blob/main/docs/VALIDATION.md).

Windows users can choose **Help → Check for app updates**. Mac/Linux users should quit and install the replacement app/package. Windows is unsigned; Mac builds are ad-hoc signed and not Apple-notarized. The production Windows feed is verified, but a full installed Beta 1-to-2 upgrade still needs a separate end-to-end test.
