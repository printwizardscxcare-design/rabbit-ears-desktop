# 0.1.0 Beta 4

- Audio controls now follow the app's selected skin, including Windows. All nine themes have matching colors, surfaces, borders, typography and controls. The open Audio window follows theme changes and reopens in the current theme without changing sound settings or presets.
- Includes the Beta 3 corrections: all normal-app menus are available; Pop out keeps the themed TV bezel, logo, dials and transport in the same window; Return restores the full app and menus.
- Caption size/color continue to apply to supplied subtitle tracks and local speech engines. Text burned into video pixels cannot be restyled.
- Desktop-only changes. Website code, deployment and saved website caption preferences are untouched.

Validation: 117 Node checks; real Electron checks for all nine audio themes on opening, changing theme and reopening; native menu dropdowns; 20 caption-style comparisons; bezel, transport and Return behavior. Real Chromium audio processing, EQ, presets and persistence checks also pass.

Windows users can choose **Help → Check for app updates**, or install the new Windows installer if upgrading from Beta 2's hidden menus. Mac/Linux users should quit and install the replacement app/package. Windows is unsigned; Mac builds are ad-hoc signed and not Apple-notarized.
