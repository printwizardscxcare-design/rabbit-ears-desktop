# Windows installation

Windows 10 or 11 on an Intel/AMD 64-bit computer.

1. [Download the Windows installer](https://github.com/printwizardscxcare-design/rabbit-ears-desktop/releases/download/v0.1.0-beta.5/Rabbit-Ears-stream-Desktop-0.1.0-beta.5-Windows-x64-Setup.exe).
2. Open Setup.exe and follow the installer. It installs for your user without administrator access.
3. Launch **Rabbit-Ears.stream Desktop** from Start or the desktop shortcut.

This beta is unsigned, so Windows may show an unknown-publisher prompt. Only use the installer from this repository’s release page.

Stream subtitles are used first; bundled Whisper fills in for missing tracks without separate setup. Windows Live Captions is an optional Windows 11 22H2+ fallback and may request speech-language files on first use.

Help → Check for app updates offers a download and asks before restarting. Remove the app from Windows Settings → Apps → Installed apps. Saved preferences remain in your user profile.
